# EcoRoute-AI: AI-Based Fuel-Efficient Route Planning

## Overview

EcoRoute-AI is an Artificial Intelligence project that compares heuristic and uninformed search algorithms for fuel-efficient route planning on a simulated road network.

Users can select a source and destination and compare the routes generated by Breadth-First Search (BFS), Greedy Best-First Search, and A* Search.

## Features

- Simulated road network with ten locations (A–J).
- Source and destination selection.
- Comparison of BFS, Greedy Best-First Search, and A*.
- Estimated distance, fuel consumption, and travel time.
- Combined route-cost calculation.
- Simulated low, medium, and high traffic conditions.
- Optional congestion simulation on a road.
- Separate route visualizations for each algorithm.
- Performance comparison charts.
- CSV export of results.

## Cost Function

The project uses the following weighted cost function:

`C = 0.40 × (T / 60) + 0.60 × (F / 5)`

Where:

- `C` = combined route cost
- `T` = estimated travel time in minutes
- `F` = estimated fuel consumption in litres

The cost function gives 40% weight to travel time and 60% weight to fuel consumption.

## Installation and Execution

Clone the repository:

```bash
git clone https://github.com/swarupbhadule199-create/EcoRoute-AI.git
```

Open the project folder:

```bash
cd EcoRoute-AI
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

## Limitations

This project uses a predefined simulated road network and simulated traffic conditions. It does not use live GPS, real-world road maps, or real-time traffic data. Fuel consumption and travel time are estimates based on the project's model.
